📚 The mathematics, in full

Every model below is implemented in the app. Read this section to know exactly why each pick has its score.

1. The base measure — Powerball is uniform i.i.d.

P(X = (w₁,w₂,w₃,w₄,w₅,b)) = 1 / [C(69,5) × 26] = 1 / 292,201,338 ≈ 3.422 × 10⁻⁹ C(69,5) = 69! / (5! · 64!) = 11,238,513

Consequence (Data Processing Inequality): for any function f of past draws X₁,…,Xₙ, I(f(X₁…Xₙ) ; X_{n+1}) ≤ I(X₁…Xₙ ; X_{n+1}) = 0 No model can extract predictive information that does not exist.

2. Frequency model

freq(i) = #{ t : i ∈ draw_t } score_F(i) = freq(i) / Σⱼ freq(j)

Under uniform sampling with N draws, E[freq(i)] = 5N/69 for whites, N/26 for PB. The chi-squared statistic χ² = Σ (freq(i) − E)² / E tests whether deviations are larger than chance.

3. EWMA hot model (exponentially weighted recent)

score_H(i) = Σₜ λ^(N−t) · 𝟙[i ∈ draw_t] λ = decay rate ∈ (0,1]; default λ = 0.985 (~ half-life of 46 draws)

Emphasises recent appearances. λ=1 → reduces to plain frequency. Smaller λ → more emphasis on recent.

4. Gap / Due model

gap(i) = N − last_seen_index(i) mean_gap_expected = 69/5 = 13.8 (whites); 26 (PB) score_D(i) = gap(i) / mean_gap_expected

Note: under i.i.d., E[gap | last seen at index k] = mean_gap regardless of k. The "due" intuition is gambler's fallacy. Included for completeness.

5. Bayesian Dirichlet–Multinomial

Prior: α₀(i) = 1 (uniform Dirichlet, k=69) Posterior: α(i) = 1 + freq(i) Posterior mean: E[p_i | data] = α(i) / Σⱼ α(j) score_B(i) = α(i) / Σⱼ α(j)

As N→∞, posterior concentrates on the true (uniform) probabilities → score_B(i) → 1/69. Bayesian update is the principled way to combine prior + data.

6. Markov pairwise (co-occurrence)

co(i,j) = #{ t : i ∈ draw_t ∧ j ∈ draw_{t−1} } score_M(i | last) = (1/5) · Σ_{j ∈ last_draw} co(i,j) / freq(j)

Conditions on which numbers appeared in the previous draw. Under i.i.d. this should be uniform; deviations indicate (spurious) coupling between draws.

7. Ensemble combiner

score(i) = w_F·score_F(i) + w_H·score_H(i) + w_D·score_D(i) + w_B·score_B(i) + w_M·score_M(i) Σ wₖ = 1 (weights softmax-normalised from user sliders) score normalised to a probability simplex over {1..69}

8. Combination ranking

For a candidate combination (a₁,…,a₅,b): combo_score = log score(a₁) + … + log score(a₅) + log score_pb(b) (log to avoid underflow; equivalent to product) Top-K combinations: generated from top-30 whites × top-10 PB then sorted by combo_score

9. Smart pick — the only feature with a real EV improvement

Cost of ticket = $2 Jackpot value = J P(jackpot win) = 1/292,201,338 P(non-jackpot) = sum of lower-tier prizes × probabilities If your combo wins and is unique: payout = J (after tax ≈ 0.6·J) If shared with k others: payout = J/(k+1) # Smart pick reduces E[shared] by avoiding popular patterns: # - all numbers ≤ 31 (birthdays) # - consecutive sequences (1,2,3,4,5) # - patterns on Powerball play slip # Selection: from ensemble top-50 whites, weight inversely by # estimated popularity. NOT a higher P(win), but higher E[payout | win].

10. Backtest metric

For each draw t ∈ {warmup+1, …, N}: fit model on draws 1..t−1 pred = top-5 whites from that model matched(t) = | pred ∩ actual_whites(t) | avg_match = mean_t matched(t) baseline = 5 × 5/69 ≈ 0.362 Two-sample test: z = (avg_match − baseline) / SE SE = sqrt(σ² / (N−warmup))
